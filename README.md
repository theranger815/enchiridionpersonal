# Enchiridion Mythic Agent Written in C

## Requirements

- Create a mythic agent in c that can fully interop with Mythic
- Agent should
  - Communicate via HTTP/HTTPs directly with Mythic
  - Work on both Windows and Linux
  - Add these command
    - print config
    - update sleep interval
    - pslist
    - netstat
    - portscan (banner and synscan)
- Stretch goals (If time permits implement these features as well)
  - reverse tunnel
  - UI Features
  - P2P Communications between agents
